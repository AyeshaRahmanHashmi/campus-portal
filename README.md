### 📖 About

Course details, class timings, notices and assignment deadlines usually live in different places. **KICSIT Student Portal** brings them together in one responsive site that works on a phone, tablet or desktop. Tasks and theme preferences are saved right in your browser, so everything is still there when you come back.

### 🗺️ Level Map — Pages

| # | Page | What it does |
|---|------|--------------|
| 01 |  **Home** (`index.html`) | Landing page with a "coming up next" glance, semester calendar, quick-access cards and upcoming events |
| 02 |  **Dashboard** (`dashboard.html`) | Registered courses, attendance by course (bars flag anything under 85%), pending assignments and upcoming events |
| 03 |  **Courses** (`courses.html`) | Course catalogue with search by name or code, plus filters by semester and enrolment status |
| 04 |  **Schedule** (`schedule.html`) | Weekly timetable with days, timings, instructors and rooms for every lecture and lab |
| 05 |  **Tasks** (`tasks.html`) | Assignment manager: add, complete and delete tasks with a due date and priority, filter and clear completed |
| 06 |  **Profile** (`profile.html`) | Student details form with validation against the university's format requirements |

<br>

### ✨ Features

```bash
$ cat features.txt
-  Dark / light mode toggle (remembered across visits)
-  Tasks saved in the browser, they survive a refresh
-  Search + filter on the course catalogue
-  Fully responsive, mobile-friendly navigation
-  Shared data layer, one data.js feeds every page
```

### 🚀 Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/AyeshaRahmanHashmi/campus-portal.git

# 2. Move into the folder
cd campus-portal

# 3. Open it, no build step needed
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

>  No installs, no servers. Just open `index.html` in any modern browser.
