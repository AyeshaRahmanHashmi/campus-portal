# KICSIT University Student Portal

Front-end prototype for the Web Technology scenario assignment (BSCS 5A and 5B).
Built with HTML5, CSS3 and vanilla JavaScript. No build step and no dependencies.

## Running the project

Open `index.html` in any modern browser. All pages are linked from the sticky navigation bar.

## Structure

```
smart-campus-portal/
  index.html          Home: hero, welcome, announcements, quick access, events, footer
  dashboard.html      Student dashboard (statistics generated by JavaScript)
  courses.html        Course cards with search and filters
  schedule.html       Weekly academic calendar: classes, labs, quizzes, assignments, events
  tasks.html          Task manager (localStorage)
  announcements.html  Announcements with category filter and search
  profile.html        Registration / profile form with inline validation
  css/style.css       Single stylesheet: tokens, global grid, components, themes
  js/theme-init.js    Applies the saved theme before first paint
  js/data.js          Courses, schedule, announcements, events, seed tasks
  js/main.js          Shared: theme, nav, toasts, storage helpers, home and dashboard widgets
  js/courses.js       Course cards, search, filtering
  js/schedule.js      Calendar grid, day cards, week navigation, type filter
  js/slider.js        Campus image slider on the home page
  js/tasks.js         Add, complete, delete, filter, persist tasks
  js/announcements.js Announcement rendering, category filter, search
  js/profile.js       Field validators, password strength, saved profile
  images/kicsitLogo.svg  University logo
  images/campus-1.png ... campus-4.png   Slider images (placeholders; replace with your PNGs)
```

## Layout system

`.grid` creates 12 equal columns inside `.container` (max width 75rem). Children span the full
width on phones and are placed with `.col-N`, `.col-sm-N` (from 640px), `.col-md-N` (from 768px)
and `.col-lg-N` (from 1024px). The navigation bar is sticky and collapses to a menu button
below 1032px.

## Validation rules (profile form)

- Registration number: `YYYY-PROGRAMME-NNN`, for example `2023-BSCS-014`
- Email: standard address format
- Phone: Pakistani mobile number, for example `0300-1234567` or `+92 300 1234567`
- Password: 8 or more characters with an uppercase letter, a lowercase letter and a number
- The password is validated in the browser and is never stored

## Notes

- Sample data (rooms, quiz dates, task due dates) is placeholder content. The two starter tasks appear only on first visit; delete them freely.
- Home page slider: changes image every 3 seconds, no captions. Save your PNGs over `images/campus-1.png` to `campus-4.png`, or list your own file names in `CAMPUS_SLIDES` in `js/data.js`.
- Quizzes are listed in `QUIZZES` in `js/data.js`; assignments on the calendar are read from the task manager's saved tasks.
- To reset the demo, clear the site's localStorage keys `mu_tasks`, `mu_profile` and `mu_theme`.
